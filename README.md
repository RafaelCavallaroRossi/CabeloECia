# ✂ Cabelo & Cia

Este projeto é um site moderno, responsivo e funcional desenvolvido para representar um **salão de beleza** na internet. O objetivo é atrair clientes, apresentar os serviços oferecidos e facilitar o agendamento online.

## ✨ Funcionalidades

- Página inicial com apresentação visual elegante
- Lista de serviços (cabelos, unhas, estética, maquiagem)
- Galeria de imagens com portfólio de trabalhos
- Página "Sobre" com missão, valores e equipe
- Formulário de contato ou agendamento
- Layout 100% responsivo para celular, tablet e desktop

## 🛠️ Tecnologias Utilizadas

- HTML5  
- CSS3  
- Tailwind
- JavaScript  
- Google Fonts

## 🎨 Design

O design foi pensado para transmitir **elegância, profissionalismo e leveza**, com uma paleta de cores suave e tipografia refinada. O site pode ser personalizado conforme a identidade visual do salão.

## 🖼️ Imagens

Imagens de alta qualidade são utilizadas para transmitir confiança e destacar os serviços oferecidos. Caso deseje substituir as imagens, basta acessar a pasta `/docs/img`.
